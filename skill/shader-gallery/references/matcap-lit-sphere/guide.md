# 매트캡 (Matcap Lit Sphere)

빛을 그린 공 텍스처 한 장으로 조명 없이 재질을 낸다

무대 종류: 메시. 난이도 1/3. 기법: 매트캡, 화면 공간 법선, 구운 조명, Unlit, 채널 패킹.

## 파일
- `MatcapLitSphere.shader`
- `core.hlsl`
- `MatcapSpheres.png`

모두 프로젝트의 `Assets/Shaders/matcap-lit-sphere/` 에 복사한다.

## 넣는 순서
1. `MatcapLitSphere.shader`, `core.hlsl`, `MatcapSpheres.png` 를 `Assets/Shaders/matcap-lit-sphere/` 에 둔다.
2. Project 창에서 `MatcapSpheres.png` 를 고르고 Inspector 에서 Texture Type 은 Default, sRGB (Color Texture) 는 끄고, Wrap Mode 는 Clamp, Filter Mode 는 Bilinear, Compression 은 None 으로 맞춘 뒤 Apply 를 누른다. sRGB 를 끄는 것은 이 텍스처가 회색조 값을 채널에 담은 데이터라서다. 그림으로 받은 컬러 매트캡 한 장을 쓸 때는 sRGB 를 켠다.
3. 셰이더를 우클릭해 Create > Material 로 머티리얼을 만들고, 매트캡 칸에 `MatcapSpheres.png` 를 넣는다.
4. 머티리얼을 대상 MeshRenderer 에 넣는다. 매트캡 채널을 Clay, Toon, Chrome 으로 바꾸고 바탕색과 합성 방식으로 재질을 맞춘다.
5. 옥처럼 속에서 비치는 느낌은 합성 방식을 Add 로, 바탕색을 어둡게 두고 테두리 색을 민트색으로, 테두리 세기를 1 정도로 올린다.

## 확인
물체를 돌리거나 Directional Light 를 돌려도 밝은 곳이 화면 왼쪽 위에 머문다. 매트캡 채널을 바꾸면 점토, 툰, 크롬으로 바뀌고, 큐브에 넣고 원근 보정을 끄면 면마다 한 색이 된다.

## 기본 머티리얼 값
| 속성 | 뜻 | 값 |
|---|---|---|
| `_Channel` | 매트캡 채널 | 점토 (R) |
| `_BaseColor` | 바탕색 | #D99978 |
| `_MatcapColor` | 매트캡 색 | #FFFFFF |
| `_Combine` | 합성 방식 | 곱하기 |
| `_Perspective` | 원근 보정 | 켬 |
| `_RimColor` | 테두리 색 | #FFFFFF |
| `_RimIntensity` | 테두리 세기 | 0 |
| `_RimPulse` | 테두리 더하기 | 0 |

## 동작 단계
1. **화면 기준 법선**: 월드 법선을 카메라의 오른쪽 축과 위 축에 내적한 값 xy 를 빨강(화면 오른쪽을 향한 정도)과 초록(화면 위를 향한 정도)으로 칠했다. 기본값(원근 보정 켬)에서 보이는 것은 카메라 축 그대로가 아니라 픽셀마다 시선 방향으로 다시 세운 축에 내적한 값이다 (두 값의 차이는 3단계에서 본다). 구는 왼쪽이 초록, 오른쪽이 주황, 아래가 빨강, 가운데가 노랑이고, 물체가 돌아도 이 배치가 화면에 그대로 붙어 있다. 큐브로 바꾸면 화면 오른쪽으로 돌아가는 면은 주황, 왼쪽으로 돌아가는 면은 초록으로 바뀐다.
2. **매트캡 한 채널**: 그 xy 를 `xy * 0.49 + 0.5` 로 텍스처 좌표로 바꿔 공 그림을 읽었다. 빛을 그려 둔 공을 화면 쪽에서 그대로 덮어씌운 셈이라 밝은 곳이 늘 왼쪽 위에 있다. 빛 계산이 없으므로 해를 돌려도 이 그림은 바뀌지 않는다. 해 방향을 따라 음영이 움직이는 [램프 툰 조명](#/s/toon-ramp-lit)과 가장 다른 점이다. 최종 화면에서는 이 값에 매트캡 색을 곱하고 바탕색과 곱하거나 더한다.
3. **원근 보정 차이**: 원근 보정을 켰을 때와 껐을 때 좌표 차이를 5배로 키워 밝기로 보였다. 카메라 정면을 지나는 화면 가운데 한 점만 검고, 거기서 멀어질수록 밝아진다. 구에서는 크롬의 수평선 띠가 조금 움직이는 정도지만, 큐브처럼 평평한 면은 보정이 없으면 면 하나가 매트캡의 한 점만 읽어 한 색으로 납작해진다.

## 주의할 점
- 이 셰이더는 불투명 3D 메시용이다. 패스가 `UniversalForwardOnly` 라 2D Renderer 에서는 그려지지 않는다. 빛을 계산하지 않는 Unlit 패스라 Directional Light 를 돌려도 음영이 그대로이고(정상, 조명이 그림에 구워져 있다) 다른 물체의 그림자를 받지 않는다. 그림자를 드리우기는 한다. 안개(Fog)도 처리하지 않는다.
- 이 표본의 채널 묶음 매트캡(`MatcapSpheres.png`, 회색조 값을 채널에 담은 데이터)은 sRGB 끔, 그림으로 받은 컬러 매트캡 한 장은 sRGB 켬이다. 채널 묶음을 sRGB 켬으로 두면 음영이 어두워지고, 컬러 매트캡을 sRGB 끔으로 두면 허옇게 뜬다. 어느 쪽이든 Wrap Mode 는 Clamp, Compression 은 None 이다. 기본값(Repeat, 압축)으로 두면 윤곽에 테가 생기고 그라데이션에 줄무늬가 진다.
- 노멀맵을 쓰려면 탄젠트 공간 노멀을 TBN(탄젠트, 바이탄젠트, 법선)으로 월드 법선으로 바꾼 뒤 같은 식(카메라 축에 내적)에 넣는다. 탄젠트 공간 노멀 xy 를 바로 쓰면 오브젝트 공간 실수와 같이 빛이 표면에 붙는다.
- 직교(Orthographic) 카메라는 모든 픽셀의 시선이 같아 원근 보정이 필요 없고, 켜도 결과가 같다.
- XR 에서는 `UNITY_MATRIX_V` 가 눈마다 달라 래퍼가 눈마다 축을 넘긴다. 원근 보정을 켜면 눈마다 시선 방향도 달라 반사가 두 눈에서 조금 다르게 보인다 (실기기 미확인). 어색하면 원근 보정을 끈다.

## 흔한 실수
- **물체나 카메라가 돌면 밝은 곳이 화면 왼쪽 위에 머물지 않는다**: 오브젝트 공간 법선 xy 를 그대로 좌표로 쓰면 매트캡이 물체 표면에 붙어 물체와 함께 돌고, 눕힌 물체는 밑에서 비춘 것처럼 보인다. 월드 법선 xy 를 쓰면 카메라가 고정된 장면에서는 그럴듯하지만 카메라가 옆이나 위로 돌아가면 빛이 월드에 붙는다. 월드 법선(`TransformObjectToWorldNormal`)을 카메라의 오른쪽 축 `UNITY_MATRIX_V[0].xyz`, 위 축 `UNITY_MATRIX_V[1].xyz` 에 내적해 화면 기준으로 바꾼다.
- **윤곽에 검은 테나 엉뚱한 색 테가 생긴다**: 세 가지 원인이 있다. (1) Wrap Mode 가 Repeat 이면 윤곽에서 반대편 가장자리 텍셀이 섞인다. Clamp 로 둔다. (2) 매트캡 그림의 원판 바깥이 검정이면 Bilinear 와 밉이 그 검정을 섞는다. 원판 밖은 셰이더가 읽는 가장 큰 반지름(0.49 / 0.5 = 원판의 0.98)의 색을 같은 방향으로 늘여 칠한다. 원판 끝 한 텍셀 고리의 색으로 칠하면 그 고리가 밝은 수평선처럼 엉뚱한 값일 때 윤곽에 밝은 호가 생긴다. (3) `xy * 0.5 + 0.5` 를 그대로 쓰면 윤곽이 원판 끝 텍셀을 읽는다. 0.49 처럼 조금 줄여 원판 안만 읽는다.
- **부드러운 그라데이션에 줄무늬나 얼룩이 진다**: 텍스처 압축(BC, ASTC) 때문이다. 매트캡은 매끈한 음영이 전부라 압축 블록이 그대로 보인다. 텍스처 Inspector 에서 Compression 을 None 으로 둔다.
- **음영이 너무 어둡거나 허옇게 떠 보인다**: sRGB (Color Texture) 설정이 텍스처와 맞지 않는다. sRGB 는 채널 수가 아니라 값을 어떻게 부호화했느냐의 문제다. 이 표본의 채널 묶음 매트캡은 회색조 값을 데이터로 담았으므로 sRGB 를 끈다 (켜면 음영이 어두워진다). 그림으로 받은 컬러 매트캡 한 장은 sRGB 로 칠한 색이므로 sRGB 를 켠다 (끄면 허옇게 뜬다).
- **큐브의 면 하나가 통째로 한 색이거나 화면 가장자리에서 빛이 어긋난다**: 평평한 면은 법선이 하나라 카메라 축만 쓰면 면 전체가 매트캡의 한 점을 읽는다. 원근 보정을 켜면 픽셀마다 시선 방향으로 축을 다시 세워 같은 면 안에서도 좌표가 조금씩 달라지고, 화면 가장자리에 있는 물체도 가운데에서 본 것처럼 칠해진다.

## 변형 예시
- 마스크 텍스처로 갑옷이나 무기 같은 금속 부위에만 크롬 매트캡을 얹고 나머지는 원래 색으로 두고 싶다.
- 장소(동굴, 사막, 밤)마다 다른 매트캡을 넣어 같은 캐릭터가 분위기에 맞게 보이게 하고 싶다.
- 카메라가 옆으로 기울어도(롤) 반사가 같이 돌지 않게, 카메라 위 축 대신 월드 위 축으로 기저를 세우고 싶다.
- 직접 그리거나 받은 컬러 매트캡 한 장을 sRGB 를 켠 채 들여와, 채널을 고르지 않고 색 그대로 쓰고 싶다.
- 이미 쓰는 Unlit 툰 캐릭터 셰이더에 매트캡 하이라이트만 더하기로 얹고 싶다.

## Shader Graph 에서 쓰기
Shader Graph 에서는 Custom Function 없이 만든다. Normal Vector 노드의 Space 를 View 로 두면 카메라 축에 내적한 화면 기준 법선이 나온다. Split 으로 R, G 를 꺼내 Vector 2 로 묶고 Multiply 0.49, Add 0.5 를 거쳐 Sample Texture 2D 의 UV 에 넣는다. 원근 보정은 이 식에 들어 있지 않다. Unity 의 Shader Graph Feature Examples 샘플에 같은 그래프("Mat Cap")가 있다.
