# 지면 범위 표시 (Ground AoE Indicator)

바닥과 소품 위에 스킬 범위를 투영해 그린다

무대 종류: 깊이 사용. 난이도 3/3. 기법: 깊이 텍스처, 위치 복원, 박스 투영, SDF, 화면 공간 데칼.

## 파일
- `GroundAoeIndicator.shader`
- `core.hlsl`
- `GroundIndicatorCharge.cs`

모두 프로젝트의 `Assets/Shaders/ground-aoe-indicator/` 에 복사한다.

## URP 설정
사용 중인 URP Asset 에서 켠다: Depth Texture.

## 넣는 순서
1. `GroundAoeIndicator.shader`, `core.hlsl`, `GroundIndicatorCharge.cs` 를 `Assets/Shaders/ground-aoe-indicator/` 에 둔다.
2. 사용 중인 URP Asset(Project Settings > Quality 에 연결된 것)의 Depth Texture 를 켠다.
3. 셰이더를 우클릭해 Create > Material 로 머티리얼을 만든다.
4. `GameObject > 3D Object > Cube` 로 상자를 만들고 Box Collider 를 지운다. 머티리얼을 넣고 납작하게 늘려 (예: Scale 4, 1, 4) 상자 높이의 가운데가 지면 높이에 오게 둔다 (지면이 상자를 위아래로 가르게). 상자 높이 안에 들어온 표면에만 표시가 붙고, 위아래 끝으로 갈수록 흐려진다.
5. 시전 연출이 필요하면 상자에 `GroundIndicatorCharge` 를 붙이고 스킬을 쓸 때 `Cast(1.5f)` 를 호출한다. 시전 전에는 숨고, 다 차면 다시 숨는다. 늘 보이는 사거리 표시는 `hideWhenIdle` 을 끈다.

## 확인
Game 뷰에서 상자 메시는 보이지 않고 바닥에 원이 보인다. 상자를 소품 쪽으로 옮기면 원이 소품 윗면으로 이어지고 옆면에는 번지지 않는다. Scale (4, 1, 4) 같은 납작한 상자에서도 기본 `옆면 문턱` 0.6 이면 상자 높이 안에 든 비탈은 약 49° 까지 그대로 칠해지고 63° 쯤에서 사라진다. 시전 진행을 올리면 가운데부터 차오른다.

## 기본 머티리얼 값
| 속성 | 뜻 | 값 |
|---|---|---|
| `_Shape` | 모양 | 원 |
| `_Radius` | 반지름 | 0.95 |

| `_ConeAngle` | 부채꼴 각도 | 90 |
| `_BorderWidth` | 테두리 두께 | 0.06 |
| `_FillDensity` | 안쪽 채움 진하기 | 0.3 |
| `_Fill` | 시전 진행 | 0 |

| `_Intensity` | 밝기 | 1.5 |
| `_SideFade` | 옆면 문턱 | 0.6 |

## 동작 단계
1. **되살린 위치**: 상자 앞면의 픽셀마다 씬 깊이로 그 시선 위의 실제 표면 위치를 되살려 같은 간격의 격자를 그었다 (x 빨강, y 초록, z 파랑). 바닥에는 빨강·파랑 격자가 깔리고, 소품 앞면에는 파랑 세로줄과 초록 가로줄이 생긴다. 파랑 세로줄이 바닥의 파랑 줄과 소품 밑동에서 만나면 복원이 맞다. 공은 상자 안에 든 오른쪽 가장자리 조각만 바닥 격자와 떨어져 보인다. 검게 보이는 곳은 상자 밖이다.
2. **상자 공간과 버리기**: 되살린 위치의 상자 공간 x 를 빨강, z 를 초록으로 칠했다. 앞 왼쪽 모서리가 어둡고 오른쪽으로 빨강, 안쪽으로 초록, 오른쪽 안(소품)은 노랑이다. 상자 밖(먼 바닥, 하늘)은 검정으로 버려 상자 메시 모양이 아니라 상자 안 표면만 남는다.
3. **모양**: xz 로 원, 고리, 부채꼴의 SDF 를 그렸다. 흰 띠가 테두리, 회색 안쪽이 채움이고 가장자리 쪽이 조금 밝다. 소품의 앞면에는 같은 모양이 세로로 늘어나 칠해져 있다. 다음 단계가 이것을 지운다.
4. **옆면 감쇠**: 같은 시선 위의 씬 표면을 이번에는 월드 위치로 되살려, 그 화면 미분 두 개(`ddx`, `ddy`)를 외적해 표면 법선을 구했다. 상자 공간 위치로 재면 상자를 납작하게 늘렸을 때 기울기가 바뀌기 때문이다. 흰색이 위를 향한 면(바닥, 소품 윗면, 공 꼭대기)이고 검정인 옆면에서는 표시를 지운다. 물체가 바닥에 닿는 경계는 미분이 2×2 픽셀 단위라 계단져 보인다.

## 주의할 점
- URP 의 Decal Projector 는 Shader Graph 의 Decal 머티리얼만 받아 이 HLSL 셰이더를 넣을 수 없다. 이 표본은 상자 메시와 머티리얼 하나로 같은 박스 투영을 직접 한다. 표면의 조명과 법선까지 받는 데칼이 필요하면 URP 내장 Decal 이 낫다.
- Depth Texture 가 꺼져 있으면 Scene 뷰에는 보이는데 Game 뷰에 표시가 없다. URP Asset 이 품질 단계마다 따로 있으면 모두 켠다. XR 과 모바일에서는 Depth Texture 가 깊이 복사나 프리패스 비용을 더하므로 그 플랫폼의 에셋에서 켤지 정한다.
- 상자 안에 서 있는 캐릭터나 기둥도 위를 향한 면(머리, 어깨, 소품 윗면)은 칠해진다. 상자를 바닥 높이 근처로 낮게 둔다. 캐릭터를 빼는 스텐실 방식이 있지만 이 표본에서는 확인하지 않았다.
- 깊이 텍스처에 들어가지 않는 투명 물체(물, 유리)에는 투영되지 않고 그 아래 바닥에 붙는다.
- 카메라가 상자 안에 들어가면 앞면이 잘려 표시가 사라진다 (`Cull Back`). 뒷면을 그리고 깊이 비교를 바꾸는 설정(`Cull Front`, `ZTest Greater`)으로 피하는 방법이 알려져 있지만 확인하지 않았다. 직교 카메라는 시선이 평행해 이 위치 복원 식이 맞지 않는다.
- 비용은 화면에서 상자가 덮는 넓이에 비례한다 (픽셀마다 깊이 한 번). 상자를 범위보다 크게 두지 않는다. Batching Static 을 켜면 `positionOS` 가 월드 위치가 되어 상자 공간이 깨지므로 표시 상자는 정적 배칭에서 뺀다. 이 셰이더는 `UniversalForward` 패스만 있어 2D Renderer 에서는 그려지지 않는다. 3D 프로젝트용이다. 안개도 처리하지 않아 Fog 를 켠 넓은 지형에서 먼 표시가 안개에 묻히지 않고 밝게 남는다. `#pragma multi_compile_fog` 를 넣고 정점에서 `ComputeFogFactor(positionCS.z)` 를 넘겨 마지막 색에 `MixFog(color, fogFactor)` 를 씌운다 (알파 혼합이므로 `MixFog`).

## 흔한 실수
- **표시가 아예 안 보인다**: Scene 뷰에는 보이는데 Game 뷰에만 없으면 사용 중인 URP Asset 의 Depth Texture 가 꺼져 있다. Project Settings > Quality 에 연결된 URP Asset 마다 켠다. 모바일용 에셋은 기본으로 꺼져 있다. 두 뷰 모두에서 안 보이면 상자를 바닥 위에 올려 놓아 지면이 상자 밑면(상자 공간 y = -0.5)에 왔다. 상자 위아래 끝은 높이 감쇠로 0 이 되므로, 상자 높이의 가운데가 지면 높이에 오게 둔다.
- **표시가 바닥이 아니라 상자 앞면에 서 있다**: 상자 표면 위치(`positionOS`)를 그대로 썼다. 씬 깊이로 시선을 늘여 뒤에 있는 실제 표면 위치를 되살린 뒤 그 xz 로 모양을 그려야 한다.
- **물체 윤곽을 따라 가는 선이나 빈틈이 생긴다**: `fwidth` 로 경계 폭을 잡으면 깊이가 끊기는 윤곽에서 이웃 위치가 멀리 튀어 폭이 커진다. 경계는 고정 폭으로 부드럽게 한다. 옆면 감쇠의 법선에는 같은 문제가 남는다. `ddx`, `ddy` 가 2×2 픽셀 묶음 안에서 윤곽 건너편 위치와의 차를 재므로, 소품이 바닥에 닿는 선을 따라 법선이 틀어져 표시가 점선처럼 끊긴다 (최종 화면의 소품 밑동). 이웃 깊이를 몇 번 더 읽어 깊이 차가 작은 쪽으로 미분하면 줄어든다고 알려져 있지만 이 표본에서는 확인하지 않았다.
- **소품 옆면에 세로 줄무늬가 흘러내린다**: 위에서 내려 찍는 투영이라 옆면에서는 모양이 세로로 늘어난다. 되살린 위치를 `ddx`, `ddy` 로 미분해 외적한 법선의 위쪽 성분이 작은 면을 흐리게 한다 (`옆면 문턱`). 이 미분은 월드 위치로 한다. 상자 공간 위치로 하면 Scale (4, 1, 4) 같은 납작한 상자에서 경사(tan)가 네 배로 읽혀 16° 비탈부터 흐려지고 26° 를 넘으면 원이 끊긴다.
- **카메라가 가까이 가면 표시가 통째로 사라진다**: 카메라가 상자 안에 들어가 앞면이 잘렸다. 상자를 카메라가 들어가지 않을 높이로 낮게 두거나, 카메라가 안에 있을 때 다른 방법으로 그린다.

## 변형 예시
- 플레이어가 마우스로 가리키는 지면 위치를 따라 다니는 스킬 조준 원으로 쓰고 싶다.
- 부채꼴 방향을 캐릭터가 바라보는 방향에 맞추고 싶다.
- 여러 적의 공격 예고를 동시에 띄우고 각자 다른 시간으로 차오르게 하고 싶다.
- 원 안에 텍스처(룬 문양)를 회전시켜 넣고 싶다.

## Shader Graph 에서 쓰기
Shader Graph 에서는 Scene Depth 노드(Eye 모드)와 Screen Position 노드(Raw 모드)의 w 로 씬 깊이와 이 픽셀의 깊이를 얻고, Camera 노드의 Position 을 Transform 노드(World → Object, Position)로 상자 공간에 옮긴다. 위치 복원 식은 Position 노드(Object)와 이 값으로 Multiply, Add 노드를 이어 만든다. `groundAoePie` 는 String 모드 Custom Function 으로 옮긴다. Name 을 `GroundAoePie` 로 하고 입력 포트 P(Vector 2), HalfAngle, Radius 와 출력 포트 D(Float) 를 만든 뒤, Body 칸에는 함수 몸체(중괄호 안)만 붙인다. 인자 이름을 포트 이름으로 바꾸고 마지막 `return max(toArc, toRay);` 는 `D = max(toArc, toRay);` 로 바꾼다. 옆면 감쇠의 법선은 월드 위치로 잰다. Position 노드(World)에서 View Direction 노드(World) × 깊이 차(씬 깊이 - 이 픽셀의 깊이) ÷ |Dot Product(View Direction, Camera 노드의 Direction)| 를 빼 씬 표면의 월드 위치를 만들고, DDX, DDY 노드와 Cross Product 노드로 미분해 외적한다.
