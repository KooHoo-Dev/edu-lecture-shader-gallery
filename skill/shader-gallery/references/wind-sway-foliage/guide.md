# 바람 흔들림 (Wind Sway Foliage)

정점을 높이에 따라 흔들어 바람을 만든다

무대 종류: 메시. 난이도 2/3. 기법: 정점 변형, 노이즈, UV 마스크, 양면 렌더링, 그림자 패스.

## 파일
- `WindSwayFoliage.shader`
- `core.hlsl`
- `WindGust.cs`

모두 프로젝트의 `Assets/Shaders/wind-sway-foliage/` 에 복사한다.

## 넣는 순서
1. `WindSwayFoliage.shader`, `core.hlsl`, `WindGust.cs` 를 `Assets/Shaders/wind-sway-foliage/` 에 둔다.
2. Project 창에서 셰이더를 우클릭해 Create > Material 로 머티리얼을 만든다.
3. 풀 메시의 MeshRenderer 에 머티리얼을 넣는다. 메시는 피벗이 뿌리(y = 0)에 있고 UV 의 v 가 뿌리 0 에서 끝 1 이어야 한다. 바람 방향은 Transform 의 Y 회전처럼 각도로 넣는다 (0 은 +Z, 90 은 +X). 오브젝트 공간 기준이라 회전하지 않은 풀에서는 월드와 같다.
4. 돌풍이 필요하면 같은 오브젝트에 `WindGust` 를 붙인다. 폭발이나 탈것 통과 같은 이벤트의 UnityEvent 에 `Gust()` 를 연결하거나, Auto Interval 에 초를 넣어 저절로 불게 한다. 머티리얼의 돌풍 값은 0 으로 둔다. 스크립트가 잠깐 올렸다 0 으로 되돌린다.

## 확인
바람 세기를 올리면 잎 끝이 바람 방향 쪽으로 더 깊이 눕고 뿌리는 제자리에 있으며, 바닥 그림자도 잎과 함께 흔들린다. 바람 방향을 270 으로 바꾸면 반대쪽으로 눕고, `Gust()` 를 부르면 바람 세기가 얼마든 잠깐 더 깊이 누웠다가 돌아온다.

## 기본 머티리얼 값
| 속성 | 뜻 | 값 |
|---|---|---|
| `_WindAngle` | 바람 방향 | 90 |
| `_WindStrength` | 바람 세기 | 0.45 |
| `_Gustiness` | 돌풍 변화 | 0.7 |
| `_WindSpeed` | 바람 속도 | 1 |
| `_Flutter` | 잎 떨림 | 0.04 |
| `_Gust` | 돌풍 | 0 |
| `_RootColor` | 뿌리 색 | #2E5B23 |
| `_TipColor` | 끝 색 | #C4D96A |

## 동작 단계
1. **흔들림 마스크**: 잎을 세로로 반 갈라 한쪽에는 `uv.y`(뿌리 0, 끝 1)를, 다른 쪽에는 그 제곱을 칠했다. 둘 다 뿌리는 검고 끝은 희지만, `uv.y` 쪽은 위로 고르게 밝아지고 제곱한 쪽은 아래쪽이 오래 어둡게 남다가 끝 가까이에서 빠르게 밝아진다. 그래서 잎 아래쪽이 세로로 밝은 줄과 어두운 줄로 갈려 보인다. 제곱한 값을 곱해 밀기 때문에 밝은 곳일수록 크게 움직이고 어두운 아래쪽은 거의 제자리에 있어, 막대처럼 통째로 기울지 않고 줄기가 휜다. 단계 보기는 색만 바꾸고 움직임은 어느 단계에서나 최종과 같다.
2. **큰 흔들림**: 바람 방향은 하나로 두고 세기만 바꾼다. 잎의 밝기가 그 자리의 돌풍 노이즈다. 흰 잎은 돌풍이 센 자리라 깊이 눕고, 검은 잎은 덜 눕는다. 노이즈 덩어리가 바람 방향으로 흘러가 잎마다 밝기와 기울기가 함께 바뀐다. 섞어 둔 느린 사인 물결도 같은 쪽으로 흐른다. 민 만큼 끝을 내려 잎 길이는 그대로다. 돌풍 버튼은 이 세기에 `_Gust` 를 더해 어느 세기에서도 바람을 키운다.
3. **떨림 더하기**: 잎마다 위상이 다른 작은 사인 흔들림을 더했다. 잎의 밝기는 지금 떨림이 어느 쪽 끝에 있는지다. 흰 잎과 검은 잎은 서로 반대쪽으로 떨고, 잎마다 제 박자로 밝아졌다 어두워진다. 위상은 잎의 오브젝트 공간 위치(`positionOS.xz`)에서 얻는다. 수업 `FishSwim` 이 몸통 축 위치에 따라 사인으로 흔드는 것과 같은 원리다. 위치로 정하므로 한 잎 안에서도 정점마다 위상이 조금 다르다. 위치에 곱하는 계수를 작게 두어 한 잎 안에서는 크게 갈리지 않게 했다. 계수를 키우면 이웃 잎과 더 어긋나지만 떨림을 올릴 때 잎이 꼬인다.
4. **양면 조명**: 잎 색을 빼고 조명만 보았다. 잎은 뒷면도 그리지만 법선은 앞면 하나뿐이라, 보통 조명식이면 빛을 등진 면을 보이는 잎이 환경광만 받아 어둡게 가라앉는다. 직사광을 `abs(dot(N, L))` 로 구해 앞면이든 뒷면이든 빛을 마주한 정도만큼 똑같이 밝힌다. 그래서 거의 모든 잎이 흰색에서 밝은 회색이고, 빛과 나란히 선 잎만 회색으로 어둡다. 얇은 잎은 빛이 비쳐 뒷면도 밝으므로 받아들일 만한 근사다. 최종 화면은 이 조명에 뿌리에서 끝으로 바뀌는 잎 색을 곱한다. 법선은 다시 계산하지 않는다. 그림자 패스도 같은 정점 함수를 불러 바닥 그림자가 잎과 함께 흔들린다.

## 주의할 점
- 이 셰이더는 불투명 3D 메시용이다. 2D Renderer 는 `Universal2D` 와 `SRPDefaultUnlit` 태그만 그리므로 `UniversalForwardOnly` 패스가 그려지지 않는다. 3D 프로젝트(Universal Renderer)에서 쓴다.
- 바람 방향, 세기, 노이즈는 오브젝트 공간에서 계산한다. 풀 오브젝트를 Y 로 돌리면 바람 방향도 함께 돌고, 스케일을 키우면 흔들림도 함께 커진다. 풀은 돌리지 않고 놓거나, 돌린 만큼 바람 방향 값을 빼서 넣는다.
- 정적 배칭: Batching Static 을 켠 물체는 플레이와 빌드에서 정점이 월드 좌표로 합쳐져 `positionOS` 가 월드 위치가 된다. 그러면 바람 방향과 돌풍 노이즈, 떨림 위상이 월드 기준으로 바뀌어, Y 로 돌린 풀은 편집 모드와 플레이 모드에서 다른 쪽으로 분다. 바닥 높이가 0 이 아니면 뿌리가 y = 0 이 아니게 되어 길이 보정도 어긋나 세게 불 때 잎이 늘어난다. 풀 오브젝트는 Inspector 의 Static 에서 Batching Static 을 끈다.
- 정점을 밀어도 Renderer 의 Bounds 는 원래 모양 그대로다. 풀이 화면 가장자리에 있으면 원래 Bounds 가 화면 밖으로 나가는 순간, 화면 안쪽으로 누운 잎까지 통째로 사라질 수 있다. 돌풍까지 더한 세기를 잎 높이의 절반 안쪽으로 두거나 메시의 `bounds` 를 넉넉히 키운다.
- Scene 뷰에서 흔들리지 않으면 Scene 뷰 툴바의 Effects 메뉴에서 Always Refresh 를 켠다. 편집 모드에서는 화면을 다시 그릴 때만 `_Time` 이 흐른다.
- 얇은 잎을 양면(`Cull Off`)으로 그리면 잎이 자기 그림자에 줄무늬(그림자 여드름)가 생길 수 있다. 생기면 Directional Light 의 Shadows > Bias 에서 Depth, Normal 값을 조금 올린다.

## 흔한 실수
- **풀이 뿌리째 바닥 위를 미끄러진다**: 흔들림 값을 모든 정점에 똑같이 더하면 뿌리도 함께 움직인다. `uv.y` 처럼 뿌리 0, 끝 1 인 값을 곱해 뿌리를 고정한다. 제곱하면 줄기가 휘어 보인다. 모델의 UV 가 이렇게 펴져 있지 않으면 정점 색 한 채널에 마스크를 칠하거나 오브젝트 공간 높이(`positionOS.y / 키`)를 쓴다.
- **잎은 흔들리는데 그림자는 가만히 있다**: `ShadowCaster` 패스의 정점 함수가 `sgVertex` 를 부르지 않으면 그림자는 원래 모양 그대로다. `DepthOnly`, `DepthNormals` 도 마찬가지라 SSAO 나 깊이를 읽는 효과가 어긋난다. 이 래퍼는 네 패스가 모두 같은 `vert` 를 쓴다.
- **모든 풀이 한 몸처럼 똑같이 흔들린다**: 떨림의 위상이 모두 같으면 풀밭이 한 장의 판처럼 움직인다. 이 표본은 `positionOS.xz` 에서 위상을 얻는다. 그런데 같은 풀 프리팹을 여러 개 놓으면 오브젝트 공간 위치가 모두 같아 덩어리끼리 똑같이 흔들린다. 래퍼의 `vert` 에서 `float3 o = TransformObjectToWorld(float3(0.0, 0.0, 0.0)); o.y = 0.0;` 를 구해 `sgVertex(v.positionOS.xyz + o, ...) - o` 로 부르면 돌풍과 위상이 월드 위치를 따른다.
- **세게 불면 잎이 늘어나 키가 커진다**: 옆으로만 밀면 뿌리에서 끝까지 거리가 늘어 잎이 길어진다. 뿌리에서 정점까지 길이를 재 두고, 민 방향으로 기울인 뒤 같은 길이로 맞춘다(`normalize` 한 뒤 원래 높이를 곱한다). 옆으로 간 만큼 끝이 내려온다. 이 계산은 뿌리가 y = 0 인 메시 기준이다.
- **Shader.SetGlobalFloat 로 바꿔도 풀이 그대로다**: `Properties` 와 `CBUFFER` 에 있는 값은 머티리얼 값이 이겨서 전역 값이 들어가지 않는다. 여러 풀을 한 번에 흔들려면 돌풍 값 `_Gust` 를 `Properties` 와 `CBUFFER` 에서 빼고, `CBUFFER` 밖에 `float _Gust;` 로 따로 선언한다. 셰이더는 지금처럼 `_Gust` 를 바람 세기에 더한다. 그러면 C# 한 줄 `Shader.SetGlobalFloat("_Gust", 값)` 이 모든 풀 머티리얼에 들어가고, 머티리얼 복사본도 만들지 않는다. `WindGust` 의 `material.SetFloat` 도 `Shader.SetGlobalFloat` 로 바꾸고 `_Gust` 를 0 에서 올렸다 0 으로 내리는 것은 그대로 둔다.

## 변형 예시
- 풀밭 전체의 풀 머티리얼을 `Shader.SetGlobalFloat` 전역 값 하나로 한꺼번에 흔드는 돌풍을 만들고 싶다.
- 같은 풀 프리팹을 여러 개 놓아도 덩어리마다 흔들림이 다르도록 월드 위치를 위상과 노이즈에 섞고 싶다.
- 플레이어가 지나가면 풀이 그 자리에서 옆으로 비켜 눕게 하고 싶다.
- UV 대신 정점 색 한 채널로 흔들림 마스크를 칠해 나무의 가지와 잎에 쓰고 싶다.
- 물고기 꼬리나 깃발처럼 한 축을 따라 사인 물결이 지나가게 바꾸고 싶다.

## Shader Graph 에서 쓰기
Shader Graph 에서는 Graph Settings 의 Render Face 를 Both 로 두고, 계산한 위치를 Vertex 의 Position 에 넣는다. Shader Graph 는 이 위치를 그림자와 깊이 패스에도 함께 쓰므로 그림자가 따로 놀지 않는다. `core.hlsl` 을 Custom Function 의 File 모드로 바로 읽으면 `SgInput` 과 머티리얼 값 선언이 없어 컴파일되지 않는다. 노드로 옮길 때는 UV 노드의 G(y)를 제곱한 마스크, Time 노드, Position(Object) 노드의 XZ 로 만든 Gradient Noise 를 같은 식으로 잇고, 길이 보정은 String 모드 Custom Function 에 `sgVertex` 의 마지막 네 줄을 옮긴다.
