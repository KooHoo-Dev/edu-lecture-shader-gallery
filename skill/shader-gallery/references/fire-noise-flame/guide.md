# 노이즈 불꽃 (Noise Flame)

흐르는 노이즈를 불꽃 모양으로 깎아 타오르게 한다

무대 종류: 메시. 난이도 1/3. 기법: UV 스크롤, 노이즈 텍스처, 모양 마스크, 임계값, 더하기 혼합.

## 파일
- `FireNoiseFlame.shader`
- `core.hlsl`
- `FireNoiseFlameNoise.png`

모두 프로젝트의 `Assets/Shaders/fire-noise-flame/` 에 복사한다.

## 넣는 순서
1. `FireNoiseFlame.shader`, `core.hlsl`, `FireNoiseFlameNoise.png` 를 `Assets/Shaders/fire-noise-flame/` 에 둔다.
2. Project 창에서 `FireNoiseFlameNoise.png` 를 고르고 Inspector 에서 Texture Type 은 Default, sRGB (Color Texture) 는 끄고, Wrap Mode 는 Repeat, Filter Mode 는 Bilinear, Compression 은 None 으로 맞춘 뒤 Apply 를 누른다.
3. 셰이더를 우클릭해 Create > Material 로 머티리얼을 만들고, 노이즈 텍스처 칸에 `FireNoiseFlameNoise.png` 를 넣는다.
4. Hierarchy 에서 3D Object > Quad 를 만들고 머티리얼을 넣는다. Rotation 은 0 으로 두어 Quad 의 앞면이 -Z 쪽(새 씬의 카메라 쪽)을 보게 하고, 불의 아래 끝이 바닥에 닿도록 Position Y 를 Scale Y 의 절반쯤으로 올린다. 이 셰이더는 그림자를 만들지 않으므로 Mesh Renderer 의 Cast Shadows 를 Off 로, 필요 없으면 Mesh Collider 를 지운다.
5. Bloom 을 쓰는 씬이면 머티리얼의 세기를 1 안팎으로 낮춘다.

## 확인
Quad 아래쪽에서 불꽃이 위로 타오르고, 가장자리가 일렁이며 속은 노랑, 바깥은 빨강이다. 흐름 속도를 0 으로 내리면 불이 멈추고, 불꽃 폭을 0.1 로 줄이면 촛불처럼 가늘어지며, 가장자리 부드러움을 0.4 로 올리면 경계가 연기처럼 흐려진다.

## 동작 단계
1. **노이즈 한 층**: 노이즈 텍스처 한 장을 UV 에 시간을 빼서 위로 흘린다. 흰 구름 사이에 어두운 얼룩이 몇 군데 있는 무늬가 Quad 전체를 덮고, 결이 세로로 길다. 재생해 보면 무늬가 통째로 위로 미끄러질 뿐 모양은 그대로다. 이것만으로는 불이 아니라 흐르는 판이다. 단계 보기는 더하지 않고 값을 그대로 그려 Quad 의 사각형이 다 보인다.
2. **두 층 곱하기**: 같은 텍스처를 두 배 잘게 한 번 더 읽어 곱하고 2 를 곱한다. 두 층이 모두 밝은 자리만 밝게 남아 1단계보다 어두운 얼룩과 가는 결이 많아진다. 화면 속도는 오프셋 속도를 반복 횟수로 나눈 값이라, 두 배로 반복한 층은 같은 오프셋을 더해도 화면에서 절반만 움직인다. 그래서 둘째 층은 오프셋 속도를 첫 층의 네 배(0.6 → 2.4)로 두어 화면에서 두 배 빠르게 오른다. 두 층의 화면 속도가 달라 겹치는 자리가 계속 바뀌므로, 재생하면 무늬가 위로 미끄러지지 않고 끓듯이 모양을 바꾼다. 불이 일렁이는 것은 이 곱셈 덕분이다.
3. **모양 마스크**: UV 만으로 만든 불꽃 모양이다. 검은 바탕에 흰 모양이 아래는 넓고 밝으며, 위로 갈수록 좁아지고 어두워져 Quad 윗변에서 사라진다. 아래 끝도 살짝 흐려 밑변이 보이지 않는다. 위쪽이 좌우로 휘는 것은 너울이다. 크고 느린 노이즈로 가로 위치를 밀되 높이를 곱해 뿌리는 제자리에 둔다. 불꽃 높이와 폭 값이 이 모양을 바꾼다.
4. **깎은 불꽃**: 마스크에 노이즈를 곱한 값을 기준값에서 `smoothstep` 으로 깎은 결과다. 흰 덩어리가 3단계의 불꽃 모양을 따르지만 가장자리는 노이즈 때문에 울퉁불퉁하다. 마스크가 옅은 위쪽은 노이즈가 밝은 곳만 남아 혀처럼 갈라지고 작은 조각이 떨어져 나간다. 이 흰 부분이 알파가 된다. 가장자리 부드러움을 키우면 경계가 흐려진다. 최종 화면은 여기에 색을 칠한 것이다. 색은 깎은 알파가 아니라 깎기 전 값이 기준값을 얼마나 넘었는지로 골라, 속은 노랑, 가운데는 주황, 가장자리는 빨강이 된다.

## 주의할 점
- 이 셰이더에는 `UniversalForward` 패스 하나만 있어 2D Renderer 에서는 그려지지 않는다. 3D 프로젝트용 효과다. 2D 에서 같은 원리를 쓰려면 스프라이트 셰이더로 옮긴다.
- Quad 는 납작한 판이라 옆에서 보면 선이 되고, 뒤에서 보면 양면을 그리므로 좌우가 뒤집힌 불이 보인다. 카메라가 돌면 스크립트로 Quad 의 Y 축만 카메라 쪽으로 돌린다. X 축까지 돌리면 위에서 볼 때 불꽃이 눕는다. Unity 기본 Plane 은 UV 가 180도 돌아 있어 불꽃이 카메라 쪽으로 누워 거꾸로 탄다.
- Particle System 의 Renderer 머티리얼로도 쓸 수 있다. 파티클 하나가 Quad 한 장처럼 불꽃 하나를 통째로 그린다. 새로 만든 Particle System 은 파티클을 계속 뿜어 수십 개가 Cone 모양으로 퍼지므로, 그대로 넣으면 같은 불꽃 여러 개가 겹쳐 하얗게 뜬다. 파티클 수와 속도, 퍼짐을 줄이고 Renderer 모듈의 Render Mode 를 Vertical Billboard 로 하면 서 있는 불꽃이 카메라를 향한다. 셰이더가 정점 색을 받아 색과 알파에 곱하므로 Start Color 와 Color over Lifetime 이 먹고, Color over Lifetime 의 알파로 서서히 나타나고 사라지게 할 수 있다. 다만 모든 파티클이 같은 무늬로 같은 순간에 일렁인다. 이 갤러리의 미리보기와 촬영은 Quad 라 파티클에서는 확인하지 못했다.
- 1 을 넘는 색은 Bloom 과 톤매핑이 없으면 채널마다 1 에서 잘리고, 톤매핑이 있으면 눌린다. 기본값은 Bloom 없이도 불로 보이게 골랐다. Bloom 을 켜면 같은 세기에서 빛이 크게 번지므로 세기를 낮춘다. 카메라의 Post Processing 과 URP Asset 의 HDR 이 켜져 있어야 HDR 값이 Bloom 까지 간다.
- 투명 물체라 깊이를 쓰지 않는다. 더하기 혼합은 그리는 순서와 상관없이 결과가 같아 불꽃끼리는 겹쳐도 정렬 문제가 생기지 않지만, 겹친 곳은 더해져 더 밝다. 순서와 상관없는 것은 불꽃끼리일 때뿐이다. 알파 혼합인 연기나 유리와 섞이면 Unity 가 물체 중심까지의 거리로 그리는 순서를 정하므로, 보는 위치에 따라 연기 뒤의 불이 연기 앞에 뜨는 식으로 앞뒤가 뒤바뀔 수 있다. 또 불꽃 밖의 빈 곳도 Quad 전체를 그리므로, 큰 Quad 나 파티클을 여러 장 겹치면 같은 픽셀을 여러 번 그려(과드로우) 모바일과 XR 에서 비용이 크다.
- 안개를 처리하지 않아 Lighting 창에서 Fog 를 켠 씬에서도 먼 불이 흐려지지 않고 그대로 밝다. 넓은 공간에 쓰면 래퍼에 안개를 넣는다 (변형 예시 참고).

## 흔한 실수
- **불꽃이 거꾸로 타거나 바닥에 눕는다**: 모양 마스크와 흐름은 UV 의 v 가 위로 커진다고 보고 만든다. Unity 기본 Quad 는 v 가 위로 커지므로 Rotation 을 0 으로 두면 아래가 뿌리가 된다. 기본 Plane 은 UV 가 180도 돌아 있어 불꽃이 카메라 쪽으로 누워 거꾸로 타므로 쓰지 않는다. 흐름은 UV 에서 시간을 빼야 위로 간다. 더하면 무늬가 아래로 흘러 불이 빨려 들어가는 것처럼 보인다.
- **사각형 판의 가장자리가 보인다**: 모양 마스크가 Quad 의 네 변에서 0 이 되어야 한다. 마스크를 빼면 효과 끄기 화면처럼 판이 통째로 타오른다. 알파를 1 로 두면 깎여 나간 곳에도 가장자리 색이 더해져 Quad 가 빨간 사각형으로 보인다. 불꽃 폭을 0.5 넘게 키우거나 너울이 너무 커서 불꽃이 옆 변까지 밀리면 그 변에서 칼로 자른 듯 끊긴다. 불꽃이 더 커야 하면 값 대신 Transform 의 Scale 로 Quad 를 키운다.
- **불이 흐르는 판처럼 미끄러지기만 한다**: 노이즈를 한 층만 흘리거나 두 층의 화면 속도가 거의 같으면 무늬가 통째로 위로 미끄러질 뿐 모양이 바뀌지 않는다. 화면 속도는 오프셋 속도를 반복 횟수로 나눈 값이다. 그래서 두 배로 반복한 층에 오프셋 속도도 두 배쯤 주면(`uv * 2 + t * 1.3` 과 `uv + t * 0.6`) 화면에서는 거의 같은 빠르기로 흐른다. 둘째 층은 원하는 화면 속도에 반복 횟수를 곱해 오프셋 속도로 쓴다. 이 표본은 첫 층의 두 배인 화면 속도 1.2 에 반복 2 를 곱해 2.4 다. 흐르는 방향을 다르게 해도 된다. 흐름 속도를 실행 중에 스크립트로 바꾸면 흐른 시간 전체에 곱해져 무늬가 한 번에 튄다.
- **불이 하얗게 날아가거나 Bloom 을 켜니 빛 덩어리가 된다**: 세기는 색에 곱하는 HDR 배율이다. 1 을 넘는 채널은 톤매핑이 없으면 1 에서 잘리고 톤매핑이 있으면 눌려서, 어느 쪽이든 속이 흰빛에 가까워진다. Bloom 이 있으면 그 값이 주변으로 크게 번진다. 기본값 1.5 는 Bloom 없이도 불로 보이게 고른 값이다. Bloom 을 켠 씬에서는 세기를 1 안팎으로 낮추고 Bloom 의 Threshold 와 Intensity 를 함께 맞춘다.
- **불이 작고 어둡거나 무늬 없이 멈춰 있다**: 노이즈 텍스처의 sRGB 가 켜져 있으면 값이 어둡게 휘어 불이 작아지고 구멍이 많아진다. 노이즈는 색이 아니라 데이터라 sRGB 를 끈다. Wrap Mode 가 Clamp 이면 흐르는 순간 가장자리 픽셀이 세로 줄로 늘어나므로 Repeat 로 둔다. 텍스처 칸이 비어 있으면 무늬 없는 매끈한 불꽃이 움직이지 않는다.

## 변형 예시
- Particle System 의 Renderer 머티리얼로 써서 카메라를 향하는 불꽃 몇 개를 띄우고 싶다. 새 Particle System 그대로는 불꽃이 너무 많이 겹쳐 하얗게 뜨니 파티클 수와 퍼짐을 알맞게 줄이고, Color over Lifetime 으로 색이 바뀌며 서서히 나타나고 사라지게 하고 싶다 (셰이더는 이미 정점 색을 곱한다). 파티클마다 무늬도 서로 어긋나게 하고 싶다.
- Quad 하나로 만든 모닥불이 카메라를 따라 세로 축으로만 돌아 늘 정면으로 보이게 하고 싶다.
- 횃불을 켜고 끌 때 불꽃 높이가 서서히 커지고 줄어들게 하고 싶다.
- 바람이 부는 방향으로 불꽃 위쪽이 한쪽으로 기울게 하고 싶다.
- 불꽃 아래쪽에 장작이 달아오른 듯한 붉은 빛을 바닥에 깔고 싶다.
- Fog 를 켠 넓은 씬에서 멀리 있는 불이 안개 속으로 흐려지게 하고 싶다. 더하기 혼합이라 안개 색이 아니라 0 으로 사라져야 하므로 래퍼에서 `MixFogColor(color, half3(0, 0, 0), fogFactor)` 를 쓴다 (`#pragma multi_compile_fog` 와 정점의 `ComputeFogFactor(positionCS.z)` 가 함께 필요하다).

## Shader Graph 에서 쓰기
URP 의 Unlit Shader Graph 로 만든다 (빛을 받지 않는 발광 효과다). 아래에서 시간은 Time 노드의 Time 에 흐름 속도를 곱한 t 다. 노이즈 첫 층은 Tiling And Offset 노드의 Tiling 에 노이즈 크기, Offset 에 (0, -t × 0.6) 을 넣어 같은 텍스처를 읽는다. 둘째 층은 Tiling 을 노이즈 크기의 두 배, Offset 을 (0.37, -t × 2.4) 로 둔다. 화면 속도는 오프셋 속도 ÷ 반복 횟수라 둘째 층은 2.4 ÷ 2 = 1.2 로 첫 층(0.6)의 두 배다. 두 층을 Multiply 한 뒤 2 를 곱해 노이즈로 쓴다. h 는 UV 의 y 를 불꽃 높이로 나눠 Saturate 한 값이다. 너울은 Tiling 0.5, Offset (0.21, -t × 0.25) 로 한 번 더 읽어 0.5 를 빼고 너울 세기와 h 를 곱한 값이다. 모양 마스크는 UV 의 x 에서 0.5 를 빼고 너울을 더한 값의 절댓값을 반폭(폭 × (1 - 0.8h))으로 나눠 Saturate 하고, 제곱해 One Minus 한 것에 (1 - h²) 와 Smoothstep(0, 0.15, y) 를 곱한다. fire = 마스크 × (노이즈 + 0.3) × 2.5 를 Smoothstep(0.5 - 부드러움, 0.5 + 부드러움) 으로 깎은 값이 알파다. 색은 깎은 알파가 아니라 fire 로 고른다. heat = Saturate((fire - 0.5) ÷ 2) 를 만들어 가장자리 색과 가운데 색을 Smoothstep(0, 0.3, heat) 로 Lerp 하고, 그 결과와 속 색을 Smoothstep(0.5, 1, heat) 로 다시 Lerp 한다 (깎은 알파로 고르면 속이 거의 노랑이 된다). 색에 세기와 Vertex Color 노드를 곱해 Base Color 에, 알파에 Vertex Color 의 A 를 곱해 Alpha 에 넣는다. Graph Settings 는 Surface Type Transparent, Blending Mode Additive, Render Face Both 로 둔다.
