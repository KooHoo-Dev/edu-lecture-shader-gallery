# 인테리어 매핑 (Interior Room Mapping)

평평한 벽의 창 안에 입체 방이 보이게 한다

무대 종류: 메시. 난이도 3/3. 기법: 인테리어 매핑, 오브젝트 공간 시선, 광선-상자 교차, 텍스처 아틀라스, 해시.

## 파일
- `InteriorRoomMapping.shader`
- `core.hlsl`
- `InteriorLightsSchedule.cs`
- `InteriorRooms.png`

모두 프로젝트의 `Assets/Shaders/interior-room-mapping/` 에 복사한다.

## 넣는 순서
1. `InteriorRoomMapping.shader`, `core.hlsl`, `InteriorRooms.png`, `InteriorLightsSchedule.cs` 를 `Assets/Shaders/interior-room-mapping/` 에 둔다.
2. Project 창에서 `InteriorRooms.png` 를 고르고 Inspector 에서 Texture Type 은 Default, sRGB (Color Texture) 는 켜고, Wrap Mode 는 Clamp, Filter Mode 는 Bilinear, Advanced 의 Generate Mipmap 은 켜고, Compression 은 None 으로 맞춘 뒤 Apply 를 누른다.
3. 셰이더를 우클릭해 Create > Material 로 머티리얼을 만들고, 방 그림 아틀라스 칸에 `InteriorRooms.png` 를 넣는다.
4. `GameObject > 3D Object > Cube` 처럼 면이 오브젝트 축에 맞는 상자 메시에 머티리얼을 넣는다. 창 수는 면마다 세므로 Scale 을 늘린 건물은 그 비율대로 가로·세로 창 수를 맞춘다 (예: Scale 4, 10, 4 이면 가로 4, 세로 10). 가로 창 수 하나를 네 옆면이 같이 쓰므로, X 와 Z 스케일이 다르면 창 수 하나로 두 쌍의 면을 모두 맞출 수 없어 한 쌍의 방이 옆으로 늘어난다.
5. 시간대에 따라 불을 켜려면 건물에 `InteriorLightsSchedule` 을 붙이고 시각(`hour`)과 1초에 흐르는 시간(`hoursPerSecond`)을 정한다. 건물마다 `lightsOffsetHours` 나 `randomOffsetHours` 를 달리 주면 점등 시각이 어긋난다.

## 확인
Cube 에 넣고 Scene 뷰에서 둘레를 돌면 창마다 방 안쪽의 옆벽과 바닥이 시선에 따라 넓어지고 좁아진다. 방 깊이를 2 로 올리면 뒷벽이 작아지며 복도처럼 깊어지고, 밤을 0.9 로 올리면 외벽과 꺼진 방이 어두워지고 켜진 방만 조명 색으로 남는다.

## 동작 단계
1. **창 칸**: 면 위 좌표에 창 수를 곱해 정수 부분(`floor`)은 칸 번호로, 소수 부분(`frac`)은 칸 안 좌표로 쓴다. 칸 안 좌표를 오른쪽으로 갈수록 빨강, 위로 갈수록 초록으로 칠해, 칸마다 왼쪽 아래가 어둡고 왼쪽 위 초록, 오른쪽 아래 빨강, 오른쪽 위 노랑인 같은 그라데이션이 되풀이된다. 면은 탄젠트 없이 오브젝트 공간 법선의 주축(±X, ±Z)으로 골라 오른쪽, 위, 안쪽 축을 정했다. 윗면은 창 없는 지붕이라 이 단계에서 검정이다.
2. **부딪친 면**: 칸마다 창 뒤에 방 상자가 있다고 치고, 오브젝트 공간 시선(`positionOS - cameraPosOS`)이 상자 안에서 처음 닿는 면을 칠했다. 빨강이 옆벽, 초록이 바닥·천장, 파랑이 뒷벽이고 안쪽으로 깊을수록 어둡다. 시선이 나가는 쪽 옆벽, 바닥이나 천장, 뒷벽까지의 거리 세 개 가운데 가장 작은 것(`min`)이 닿는 면이다. 정면에 가까운 창은 파랑 뒷벽이 넓고, 비스듬히 보이는 창일수록 빨강 옆벽이 넓어진다. 무대 카메라는 상자 윗면 높이쯤이라 창마다 아래쪽에 바닥(초록)이 보인다.
3. **방 그림 좌표**: 닿은 점 (x, y, 깊이 비율 w)을 `q = xy / (1 + w)` 로 방 그림 좌표로 바꿔 q.x 를 빨강, q.y 를 초록으로 본다. 방 그림은 창에서 방 깊이만큼 물러난 눈으로 본 한 점 투시라 뒷벽(w = 1)이 그림 가운데 절반 크기에 들어간다. 흰 선은 그림 속 방 모서리(가운데 사각형과 네 대각선)인데 2단계의 면 경계와 겹친다. 면이 바뀌는 방 모서리에서도 좌표가 이어져 텍스처 이음매가 없다. 칸 경계를 따라 생기는 흰 세로줄은 칸이 바뀌며 좌표가 끊기는 자리로, 최종 화면에서는 창틀이 덮는다.
4. **방마다 다른 그림과 불**: 칸 번호 해시로 아틀라스 네 칸(사무실, 거실, 상점, 빈 방) 가운데 하나를 고르고, 절반은 좌우로 뒤집어 읽었다. 그림 한 장이 방 깊이와 보는 각도에 맞게 펴진다. 방마다 고정 난수가 불 켜진 비율보다 작으면 등이 켜져 노란빛이 돌고, 천장 가운데 등에 가까운 곳일수록 밝다. 아직 창틀, 커튼, 유리 반사가 없어 방 상자를 쌓아 놓은 것처럼 보인다.

## 주의할 점
- Batching Static 을 켜면 정점이 월드 좌표로 합쳐져 `positionOS` 와 `cameraPosOS` 가 월드 기준이 된다. 칸이 건물 모서리에 맞지 않고 방이 통째로 어긋난다. 도시 건물은 Static 을 켜 두기 쉬우므로 이 머티리얼을 쓰는 건물은 Static 메뉴에서 Batching Static 만 끈다.
- 면 방향은 오브젝트 공간 법선의 주축(±X, ±Z)으로 고르고 위아래(±Y)는 지붕으로 칠한다. 면이 오브젝트 축과 맞지 않는 메시(임포트한 건물 모델, 비스듬한 벽, 원기둥)는 창 칸과 방 방향이 틀린다. 건물을 축에 맞춰 모델링하거나 UV 와 탄젠트로 면 기저를 만드는 판으로 바꾼다.
- 칸 경계에서는 아틀라스 좌표가 끊겨 밉이 가장 작은 단계로 튄다. 이 표본은 창틀이 그 자리를 덮는다. 창틀을 아주 얇게 하거나 멀리서 보면 칸 경계에 한 픽셀 선이 보일 수 있다. 그럴 때는 `SAMPLE_TEXTURE2D_LOD(..., 0)` 으로 밉 0 을 읽거나 이어진 좌표의 미분을 `SAMPLE_TEXTURE2D_GRAD` 에 넘긴다 (이 표본은 창틀로 덮고 쓰지 않았다). 아틀라스 칸이 128 px 경계에 맞고 여백이 4 px 라 BC 압축의 4×4 블록과 밉이 방 사이에 걸치지 않는다 (Unity 촬영은 압축본인데도 번지지 않았다). ASTC 6×6 처럼 4 의 배수가 아닌 블록은 칸 경계에 걸쳐 이웃 방 색을 섞는다. BC 도 얇은 선과 넓은 단색면이 뭉개지므로 None 을 권한다.
- Shader Graph 예제의 큐브맵판(Interior Cube Mapping)은 방 하나를 큐브맵 여섯 면으로 담아, 방마다 다른 그림을 쓰려면 큐브맵을 더 둬야 한다. 이 표본의 2D 아틀라스판은 한 점 투시 그림 한 장이라 아틀라스 칸으로 방 종류를 늘리기 쉽고, 방 깊이를 머티리얼 값으로 바꿔도 같은 그림이 맞는다. 대신 방당 120 px 라 면 하나에 큰 창 하나(상점 진열창 프리셋)처럼 크게 보면 흐리다. 큰 창이 많으면 아틀라스를 키운다.
- 직교 카메라에서는 시선이 모두 카메라 정면 축과 나란해 카메라 위치에서 쏜 시선이 틀린다. 래퍼는 `unity_OrthoParams.w > 0.5` 이면 `cameraPosOS` 를 `positionOS - TransformWorldToObjectDir(GetViewForwardDir(), false)` 로 바꿔 정면 축으로 들여다본다. 인테리어 매핑은 직교 카메라를 쓰는 아이소메트릭 도시 게임에서도 쓰이니 래퍼를 고쳐 쓸 때 이 분기를 지우지 않는다 (웹 무대는 원근 카메라라 이 분기를 확인하지 않았다). XR 에서는 픽셀마다 그 눈의 카메라 위치로 시선을 쏘므로 두 눈이 서로 다른 시차를 보아 방 깊이가 맞는다 (원리상 그렇다는 추론이고 실기기에서는 확인하지 않았다). 모바일에서도 텍스처 한 번 읽기와 산술뿐이라 가볍다. 패스가 `UniversalForwardOnly` 라 2D Renderer 에서는 그려지지 않는다. 3D 프로젝트용이다.
- 외벽은 주 광원만 받고, 래퍼가 `distanceAttenuation` 을 곱하지 않아 광원의 Culling Mask 와 Rendering Layers 가 무시된다. 안개도 처리하지 않아 Fog 를 켠 도시에서 먼 건물이 안개에 묻히지 않는다. `#pragma multi_compile_fog` 를 넣고 정점에서 `ComputeFogFactor(positionCS.z)` 를 넘겨 마지막 색에 `MixFog(color, fogFactor)` 를 씌운다.

## 흔한 실수
- **창 안이 벽지처럼 납작하고 돌려 봐도 안쪽이 움직이지 않는다**: 칸 안 좌표나 UV 로 방 그림을 바로 읽었다. 시선을 방 상자와 교차시켜 닿은 점을 그림 좌표(`xy / (1 + w)`)로 바꿔 읽어야 보는 각도에 따라 옆벽과 바닥이 넓어지고 좁아진다. 효과 끄기 화면이 이 실수다.
- **방이 통째로 미끄러지거나 칸이 건물 모서리와 어긋난다**: 시선과 표면 위치가 서로 다른 공간에 있다. 월드 공간 카메라 위치와 오브젝트 공간 위치를 섞으면 건물이 돌거나 옮겨질 때 방이 따라오지 않는다. 래퍼에서 `TransformWorldToObject(GetCameraPositionWS())` 로 카메라를 오브젝트 공간으로 옮겨 `positionOS` 와 같은 공간에서 시선을 만든다. 에디터에서는 맞는데 플레이 중에만 어긋나면 Batching Static 때문이다 (Unity 주의 사항 참고).
- **방 깊이를 바꾸면 그림 속 모서리가 실제 방 모서리와 어긋난다**: 그림 좌표를 깊이의 실제 거리로 나눴거나, 방 그림을 다른 시점(창 바로 앞, 넓은 화각)에서 그렸다. 깊이는 뒷벽이 1 인 비율 w 로 쓰고 `xy / (1 + w)` 로 나눈다. 방 그림은 창에서 방 깊이만큼 물러난 눈으로 그려 뒷벽이 가운데 절반 크기가 되게 한다. 그러면 깊이가 약분되어 어떤 깊이에도 같은 그림이 맞는다.
- **창 가장자리에 한 픽셀 선이 생기거나 이웃 방 색이 번진다**: 칸 경계에서 아틀라스 좌표가 끊겨 미분이 커지고 가장 작은 밉이 읽혔다. 창틀이 그 자리를 덮게 두께를 남기거나, 밉 0 으로 읽는다. 아틀라스 칸 사이에 여백이 없으면 밉과 Bilinear 가 이웃 방을 끌어오므로, 칸 둘레에 그림 가장자리 색을 몇 픽셀 이어 칠해 둔다 (이 표본은 4 px).
- **여러 방의 불이 한꺼번에 켜졌다 꺼졌다 깜빡인다**: 불 켜짐을 시간에 따라 바뀌는 난수로 정했거나 비율을 빨리 움직였다. 방마다 고정 난수와 불 켜진 비율을 비교하면 비율이 오를 때 켜진 방은 그대로 있고 새 방만 켜진다. 비율은 몇 초에 걸쳐 천천히 바꾸고, 건물이 여럿이면 `InteriorLightsSchedule` 의 점등 오프셋으로 건물마다 시각을 어긋나게 한다.

## 변형 예시
- 같은 머티리얼을 쓰는 건물들이 모두 같은 방 배치와 같은 불 켜짐으로 보이지 않게 건물마다 다르게 하고 싶다.
- 1층은 상점 진열창, 위층은 사무실처럼 층마다 다른 방 종류와 깊이를 쓰고 싶다.
- 창 안쪽에 가구 평면을 하나 더 두어 책상이나 사람이 방 앞쪽에 서 있는 것처럼 보이게 하고 싶다.
- 임포트한 건물 모델처럼 면이 오브젝트 축과 맞지 않는 메시에도 창이 맞게 나오게 하고 싶다.
- 게임 속 시계에 맞춰 저녁에 불이 하나씩 켜지고 새벽에 꺼지게 하고 싶다.
- 멀리 있는 건물은 계산을 줄여 평평한 창 그림 한 장으로 바꾸고 싶다.

## Shader Graph 에서 쓰기
Shader Graph 의 Feature Examples 샘플에는 큐브맵판인 Interior Cube Mapping(UV Projection 분류의 `UVInteriorCubemap` 서브그래프)이 있다. 이 표본의 아틀라스판으로 옮기려면 Camera 노드의 Position 을 Transform 노드(World → Object, Position)로 옮겨 Position 노드(Object)에서 빼고 Normalize 해 오브젝트 공간 시선을 만든다. 교차와 그림 좌표는 String 모드 Custom Function 으로 옮긴다. Name 을 `InteriorPicture` 로 하고 입력 포트 Start(Vector 2, 칸 안 좌표 × 2 - 1), Ray(Vector 3, 상자 좌표로 바꾼 시선)와 출력 포트 Q(Vector 2)를 만든 뒤, Body 칸에 `core.hlsl` 의 `dirSign`, `tWall`, `tBack`, `t`, `hit` 다섯 줄을 붙이고 `start`, `ray` 를 포트 이름으로 바꾼 다음 `Q = hit.xy / (1.0 + hit.z);` 를 더한다. 칸 번호 해시와 아틀라스 칸 좌표는 Floor, Fraction, Multiply, Add 노드로 만든다.
