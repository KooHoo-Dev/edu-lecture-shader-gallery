# 홀로그램 (Hologram Scanline Glitch)

스캔라인과 글리치로 홀로그램을 만든다

무대 종류: 메시. 난이도 2/3. 기법: 프레넬, 정점 변형, 시간 양자화, 더하기 혼합, 월드 좌표.

## 파일
- `HologramScanlineGlitch.shader`
- `core.hlsl`
- `HologramGlitchBurst.cs`

모두 프로젝트의 `Assets/Shaders/hologram-scanline-glitch/` 에 복사한다.

## 넣는 순서
1. `HologramScanlineGlitch.shader`, `core.hlsl`, `HologramGlitchBurst.cs` 를 `Assets/Shaders/hologram-scanline-glitch/` 에 둔다.
2. Project 창에서 셰이더를 우클릭해 Create > Material 로 머티리얼을 만든다.
3. 머티리얼을 홀로그램으로 보일 물체의 MeshRenderer 에 넣는다. 정점이 너무 성기지 않은 메시(기본 구 이상)를 쓴다.
4. 끊김 연출이 필요하면 같은 오브젝트에 `HologramGlitchBurst` 를 붙이고 끊기는 순간에 `Burst()` 를 호출한다. 인자가 없어 Inspector 의 UnityEvent 에 바로 연결할 수 있다.
5. 빛이 번지는 느낌을 원하면 URP Asset 의 HDR 을 켜고 Volume 에 Bloom 을 더한다. 없어도 효과는 보인다.

## 확인
Play 하면 윤곽이 하늘색으로 빛나고 수평 줄이 위로 흐르며, 가끔 가로 띠가 옆으로 툭 밀렸다 돌아온다. 물체를 돌려도 줄은 수평을 유지하고, 글리치 세기를 0 으로 내리면 띠가 멈춘다.

## 기본 머티리얼 값
| 속성 | 뜻 | 값 |
|---|---|---|
| `_HoloColor` | 홀로그램 색 | #3DDCFF |
| `_RimPower` | 테두리 좁히기 | 2 |
| `_LineSpacing` | 스캔라인 간격 | 0.08 |
| `_ScanSpeed` | 스캔라인 속도 | 0.3 |
| `_GlitchStrength` | 글리치 세기 | 0.5 |
| `_Flicker` | 깜빡임 세기 | 0.35 |
| `_Dropout` | 전송 끊김 | 0 |

## 동작 단계
1. **프레넬**: 법선과 시선이 비스듬할수록 밝다. 가운데는 검고 윤곽으로 갈수록 밝아져 테두리가 흰 고리가 된다. 홀로그램이 속이 빈 빛의 껍데기처럼 보이는 바탕이다.
2. **스캔라인**: 월드 높이 `positionWS.y` 를 간격으로 나눠 `frac` 한 흰 줄과 검은 틈이다. 시간을 빼서 위로 흐른다. 구가 돌아도 줄은 늘 수평이고, 글리치로 밀려난 조각에서도 줄이 월드 높이를 따라 다시 그어진다.
3. **글리치 띠 마스크**: 구를 가로 띠 네다섯 개로 나눈 모습이다. 어두운 회색과 조금 밝은 회색이 번갈아 띠 폭을 보여 주고, 지금 옆으로 밀려난 띠만 흰색이다. 시간을 `floor` 로 0.1 초 칸에 끊어 고르므로 흰 띠는 멈춰 있다가 한 번에 바뀐다. 흰 띠가 안 보이면 잠시 기다리거나 전송 끊김 버튼을 누른다.
4. **합치기**: 테두리, 옅은 몸통, 스캔라인을 더한 밝기에 깜빡임을 곱했다. 바닥이 비치지 않게 화면에 더해질 빛만 꺼내 본 모습이고, 최종 화면에서는 이 빛이 더하기 혼합으로 바닥 위에 얹힌다. 0.5 초 칸마다 반반 확률로 몸 전체가 조금 어두워진다. 밀린 띠가 흰빛으로 바래는 것은 전송 끊김 중일 때뿐이다.

## 주의할 점
- 이 셰이더에는 `UniversalForward` 패스만 있어 2D Renderer 에서는 그려지지 않는다. 3D 프로젝트용 효과다.
- 글리치 띠는 오브젝트 공간 높이 `positionOS.y` 로 나누고 미는 거리도 오브젝트 공간 값이다 (스캔라인만 월드 기준이라 늘 수평). 캐릭터처럼 Blender 에서 FBX 로 가져온 모델은 Transform 이 회전 X -90, 크기 100 으로 들어오는 일이 많은데, 그러면 띠가 세로로 서거나 정점이 한 띠에 뭉치고 미는 거리가 100 배로 커진다. Blender 의 FBX 내보내기에서 Apply Scalings 를 FBX All 로 두고 Apply Transform 을 켜거나, Unity 모델 Import Settings 의 Bake Axis Conversion 으로 회전을 정점에 굽혀, 물체의 Transform 이 회전 0, 크기 1 이 되게 맞춘다. XR 에서 손에 든 물체가 기울면 띠도 물체를 따라 기울고 스캔라인은 수평으로 남는다. Batching Static 으로 정적 배칭된 물체는 정점이 월드 좌표로 합쳐져 `positionOS` 가 월드 위치가 되므로 홀로그램 물체는 Static 에서 Batching Static 을 끈다.
- 정점을 옆으로 밀어도 메시의 바운드는 그대로다. 물체가 화면 가장자리에 있어 바운드가 화면 밖으로 나가면 컬링되어, 화면 안으로 밀려 나온 띠까지 통째로 사라진다. 미는 거리(최대 0.18)가 작아 가장자리에서만 생기지만, 문제가 되면 C# 에서 `Renderer.localBounds` 를 미는 거리만큼 넓힌다.
- 투명 물체라 그림자를 만들지 않고 깊이 텍스처에도 들어가지 않는다. 깊이를 읽는 다른 효과(역장 교차선 등)는 홀로그램을 보지 못한다.
- XR 에서는 투명 면이 겹칠수록 픽셀을 여러 번 칠한다(과드로우). 큰 홀로그램 여러 개를 겹치면 모바일 XR 기기에서 프레임이 떨어질 수 있다.
- Play 중 셰이더의 `_Time` 은 `Time.timeScale` 을 따른다. 배속 3 이면 셰이더 깜빡임이 3Hz, 글리치가 초당 30 번으로 빨라지고, 0 이면 멈춘다. 배속이 있는 게임에서는 머티리얼의 `_Flicker`(깜빡임 세기)를 0 으로 둔다. `HologramGlitchBurst` 의 제한은 실제 시간으로 세므로 배속과 상관없다.

## 흔한 실수
- **스캔라인이 메시 이음매에서 끊기거나 물체를 따라 돈다**: UV 로 줄을 그리면 UV 가 잘린 이음매에서 줄이 어긋나고, 물체가 기울면 줄도 같이 기운다. 캐릭터처럼 UV 가 조각난 메시에서는 줄 간격도 부위마다 달라진다. 정점에서 `TransformObjectToWorld` 로 구한 월드 위치의 y 를 쓴다.
- **글리치가 디지털 끊김이 아니라 물결처럼 출렁인다**: `sin(time)` 처럼 매끄러운 시간을 그대로 쓰면 띠가 부드럽게 미끄러진다. `floor(time * 10.0)` 으로 시간을 칸으로 끊고 그 칸 번호로 난수를 뽑아야 멈춰 있다가 한 번에 튄다.
- **밀린 띠가 계단이 아니라 혹처럼 꿈틀대 보인다**: 정점을 미는 효과는 정점만 움직이고 그 사이 삼각형은 늘어난다. 위아래 정점이 서로 다른 띠에 걸친 경계 한 칸은 정점 간격이 얼마든 늘 비스듬히 찢어진다. 그래서 띠 안에 곧게 밀리는 칸이 남도록 띠 폭을 정점 간격의 두 배 이상으로 둔다. Unity 기본 구는 정점 간격이 약 0.1 이라 띠 폭을 0.25(`HOLOGRAM_GLITCH_BANDS` 4)로 두었다. 0.2 로 좁히면 곧은 칸이 거의 없어 띠가 혹처럼 보인다. 로우폴리 모델은 띠 수를 더 줄이거나 모델을 잘게 나눈다.
- **뒤에 있는 홀로그램이 사라지거나 겹친 곳이 깨진다**: 투명 물체가 `ZWrite On` 이면 앞 물체가 깊이를 차지해 뒤 물체가 그려지지 않는다. 이 셰이더는 `ZWrite Off` 와 더하기 혼합이라 순서와 상관없이 빛이 더해진다. 알파 혼합으로 바꾸면 겹친 투명 물체의 정렬 문제가 다시 생긴다.
- **깜빡임이 눈을 찌르거나 배속에서 빨라진다**: 물체 전체가 빠르게 반복해 밝아졌다 어두워지면 광과민 발작 위험이 있다. 셰이더 깜빡임은 `HOLOGRAM_FLICKER_RATE` 2 라 보통 속도에서는 밝기가 초당 2 번까지만 바뀌지만, Play 중 `_Time` 은 `Time.timeScale` 을 따라 배속 3 이면 깜빡임이 3Hz, 글리치가 초당 30 번이 된다. 배속이 있는 게임에서는 `_Flicker` 를 0 으로 둔다. `HologramGlitchBurst` 는 실제 시간으로 세어 초당 3 회를 넘지 않게 막지만 셰이더 깜빡임과 합쳐 세야 하므로 `Burst()` 를 자주 부르면 `_Flicker` 도 낮춘다. 시간만으로 고르므로 같은 머티리얼을 쓰는 홀로그램은 모두 같은 순간에 어두워지고 같은 띠가 튀어, 번쩍이는 면적이 그만큼 커진다. 물체마다 어긋나게 하려면 래퍼에 `_TimeOffset` 속성(CBUFFER 안)을 더해 `_Time.y + _TimeOffset` 을 `sgVertex` 와 `i.time` 에 넘기고, C# `Awake` 에서 `renderer.material` 복사본에 `Random.Range(0f, 10f)` 를 넣는다.

## 변형 예시
- 캐릭터 모델에 씌워 통신 화면 속 인물처럼 보이게 하고 싶다.
- XR 에서 손으로 잡은 물체만 홀로그램 미리보기로 바꾸고 싶다.
- 홀로그램이 아래에서 위로 서서히 나타나는 등장 연출을 넣고 싶다.
- 밀린 띠에 빨강과 파랑이 갈라지는 색수차를 넣고 싶다.
- 바닥의 투영기에서 빛줄기가 올라오는 느낌을 더하고 싶다.

## Shader Graph 에서 쓰기
Shader Graph 에서는 Fresnel Effect 노드로 테두리를, Position(World) 노드의 Y 를 간격으로 나눠 Fraction 노드로 스캔라인을 만든다. 정점 글리치는 Custom Function 노드에서 `sgVertex` 를 불러 Vertex Position 에 연결하고, Time 노드의 Time 을 그대로 넘긴다. `sgVertex` 가 안에서 `floor(time * 10.0)` 으로 끊으므로 미리 Floor 로 끊어 넘기면 띠가 1 초에 한 번만 바뀐다.
