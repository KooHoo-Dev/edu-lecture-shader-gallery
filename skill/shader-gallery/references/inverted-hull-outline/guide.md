# 껍데기 외곽선 (Inverted Hull Outline)

부풀린 뒷면을 한 번 더 그려 외곽선을 만든다

무대 종류: 메시. 난이도 2/3. 기법: 멀티 패스, Cull Front, 정점 변형, 외곽선, 선택 표시.

## 파일
- `InvertedHullOutline.shader`
- `core.hlsl`
- `HullOutlineSelection.cs`

모두 프로젝트의 `Assets/Shaders/inverted-hull-outline/` 에 복사한다.

## 넣는 순서
1. `InvertedHullOutline.shader`, `core.hlsl`, `HullOutlineSelection.cs` 를 `Assets/Shaders/inverted-hull-outline/` 에 둔다.
2. Project 창에서 셰이더를 우클릭해 Create > Material 로 머티리얼을 만든다.
3. 머티리얼을 대상 MeshRenderer 에 넣는다. Inspector 에서 외곽선 두께와 색을 맞춘다. 큐브 같은 각진 볼록 메시는 미는 방향을 FromCenter, 구나 캐릭터처럼 부드러운 메시는 Normal 로 둔다.
4. 선택 표시에 쓸 때는 같은 오브젝트에 `HullOutlineSelection` 을 붙인다. 고를 때 `Select()`, 놓을 때 `Deselect()` 를 호출한다. 인자가 없어 Inspector 의 UnityEvent(예: XR Simple Interactable 의 Hover Entered, Hover Exited)에 바로 연결할 수 있다.

## 확인
외곽선 두께를 올리면 물체 둘레의 선이 굵어지고 0 으로 내리면 사라진다. 큐브에서 미는 방향을 Normal 로 바꾸면 모서리마다 선이 끊긴다.

## 기본 머티리얼 값
| 속성 | 뜻 | 값 |
|---|---|---|
| `_OutlineWidth` | 외곽선 두께 | 0.04 |
| `_OutlineColor` | 외곽선 색 | #FFC94D |
| `_OutlineAmount` | 외곽선 켜기 | 1 |
| `_PushDir` | 미는 방향 | 중심에서 바깥 |
| `_BaseColor` | 기본 색 | #4F86C6 |

## 동작 단계
1. **본체만**: 본체는 기본 색에 조명을 곱한 음영이다. 이 단계에서는 껍데기도 같은 식으로 칠해 외곽선 색을 감췄다. 윤곽 둘레에 본체와 같은 색이지만 면과 밝기가 다른 띠가 붙어 실루엣이 살짝 부푼 것이 보인다. 그 띠가 본체 뒤에서 삐져나온 껍데기의 뒷면이다.
2. **앞면까지 그리면**: 부풀린 껍데기를 앞면까지 그리면 껍데기가 본체보다 카메라에 가까워 본체를 통째로 덮는다. 외곽선 색 덩어리만 남는다. 외곽선 패스에 `Cull Front` 를 넣는 이유다.
3. **Cull Front**: 껍데기의 앞면을 버리고 뒷면만 그린다. 뒷면은 본체 뒤에 있어 대부분 가려지고, 윤곽 바깥으로 삐져나온 띠만 남아 외곽선이 된다. `_OutlineWidth` 가 그 띠의 폭이다.

## 주의할 점
- 이 셰이더는 불투명 3D 메시용이다. 본체 패스가 `UniversalForwardOnly` 라 2D Renderer 에서는 그려지지 않는다. 3D 프로젝트에서 쓴다.
- 물체를 두 번 그리므로 외곽선을 켠 물체마다 그리기 호출이 하나씩 늘어난다. `HullOutlineSelection` 은 외곽선이 꺼진 동안 `SetShaderPassEnabled` 로 외곽선 패스를 건너뛴다. 장면의 모든 물체에 상시 외곽선이 필요하면 깊이와 법선으로 화면에서 한 번에 그리는 후처리 방식과 비교한다.
- 미는 방향 FromCenter 는 피벗이 메시 가운데 있는 볼록한 메시에서만 고르게 부푼다. 피벗이 발밑이거나 팔다리가 있는 메시는 한쪽으로 쏠린다. 이런 메시는 Normal 로 두고 부드러운 법선을 굽는다.
- 평면(Quad, Plane)처럼 뒤가 비어 있는 메시는 껍데기의 뒷면이 앞을 향해 외곽선이 면 전체를 덮거나 비어 보인다. 닫힌 메시에 쓴다.
- 외곽선 색은 조명과 그림자를 받지 않는 단색이다. 외곽선은 그림자를 드리우지 않고 깊이와 노멀 텍스처에도 들어가지 않는다.

## 흔한 실수
- **각진 메시에서 모서리마다 외곽선이 끊긴다**: 큐브나 로우폴리 소품은 모서리 정점이 면마다 따로 있고 법선도 갈라져 있다. 법선 방향으로 밀면 면이 제각기 떨어져 나가 모서리에 틈이 생긴다. 피벗이 가운데인 볼록한 메시는 이 표본의 미는 방향을 **중심에서 바깥** 으로 둔다. 캐릭터처럼 오목한 메시는 같은 자리의 법선을 평균한 부드러운 법선을 DCC 도구나 에디터 스크립트로 UV 채널(예: UV3)에 구워 두고, 래퍼의 `vertOutline` 에서 그 채널을 읽어 민다.
- **물체 전체가 외곽선 색으로 덮인다**: 외곽선 패스가 `Cull Back`(기본값)이거나 `Cull Off` 이면 부풀린 껍데기의 앞면이 본체를 가린다. 외곽선 패스에만 `Cull Front` 를 넣고 본체 패스는 그대로 둔다.
- **외곽선 패스가 아예 그려지지 않는다**: URP 는 같은 `LightMode` 태그의 패스가 둘이면 첫 패스만 그린다. 두 패스를 모두 `UniversalForward` 로 두면 외곽선이 사라진다. 외곽선 패스는 `"LightMode" = "SRPDefaultUnlit"` 으로 둔다.
- **멀리 가면 선이 가늘어지고 가까이 오면 굵어진다**: 두께가 오브젝트 공간 길이라 원근에 따라 화면 두께가 바뀐다. 화면에서 같은 두께를 원하면 래퍼의 `vertOutline` 에서 클립 공간으로 민다. 위치와 법선을 클립 공간으로 바꾼 뒤 `positionCS.xy += normalize(법선CS.xy) * 픽셀두께 * 2 / _ScreenParams.xy * positionCS.w` 처럼 화면 크기로 나누고 `w` 를 곱한다. `sgVertex` 는 오브젝트 공간 위치만 돌려주므로 이 보정은 래퍼에서 한다.
- **스케일을 키운 물체만 외곽선이 굵다**: 오브젝트 공간 두께는 Transform 스케일과 함께 커진다. 스케일이 다른 물체를 같은 두께로 보이게 하려면 C# 에서 `_OutlineWidth` 를 스케일로 나눠 넣거나, 위의 클립 공간 보정을 쓴다. 비균일 스케일이면 방향마다 두께가 달라진다.

## 변형 예시
- 카메라에서 멀어져도 외곽선이 화면에서 같은 픽셀 두께로 보이게 클립 공간 보정을 넣고 싶다.
- XR 에서 손이 다가가면(Hover) 외곽선이 켜지고, 잡으면(Select) 색이 바뀌게 하고 싶다.
- 캐릭터 메시의 부드러운 법선을 UV3 에 굽는 에디터 스크립트를 만들어 각진 갑옷에서도 선이 끊기지 않게 하고 싶다.
- 정점 색의 한 채널로 부위마다 외곽선 두께를 다르게 하고 싶다.
- 툰 셰이딩 본체와 합쳐 만화 같은 캐릭터를 만들고 싶다.

## Shader Graph 에서 쓰기
Shader Graph 는 그래프에 `Cull Front` 패스를 직접 하나 더 넣을 수 없어 이 구성을 그래프 하나로 만들 수 없다. 본체는 그래프로 만들고, 외곽선만 이 셰이더의 외곽선 패스를 떼어 낸 두 번째 머티리얼로 MeshRenderer 의 Materials 에 하나 더 넣거나 Render Objects 렌더러 기능으로 덧그린다.
