# 스크롤·왜곡 에너지 (Scroll Distort Energy)

흐르는 무늬를 겹쳐 레이저와 마법 기운을 만든다

무대 종류: 메시. 난이도 2/3. 기법: UV 스크롤, UV 왜곡, 노이즈 텍스처, 더하기 혼합, HDR.

## 파일
- `ScrollDistortEnergy.shader`
- `core.hlsl`
- `ScrollDistortNoise.png`

모두 프로젝트의 `Assets/Shaders/scroll-distort-energy/` 에 복사한다.

## 넣는 순서
1. `ScrollDistortEnergy.shader`, `core.hlsl`, `ScrollDistortNoise.png` 를 `Assets/Shaders/scroll-distort-energy/` 에 둔다.
2. Project 창에서 `ScrollDistortNoise.png` 를 고르고 Inspector 에서 Texture Type 은 Default, sRGB (Color Texture) 는 끄고, Wrap Mode 는 Repeat, Filter Mode 는 Bilinear 로 맞춘 뒤 Apply 를 누른다.
3. 셰이더를 우클릭해 Create > Material 로 머티리얼을 만들고, 노이즈 텍스처 칸에 `ScrollDistortNoise.png` 를 넣는다.
4. Hierarchy 에서 3D Object > Cylinder 를 만들고 머티리얼을 넣는다. 이 셰이더에는 ShadowCaster 패스가 없어 원래 그림자를 만들지 않으므로, 그림자 계산에서 빼려면 Mesh Renderer 의 Cast Shadows 를 Off 로 둔다. 필요 없으면 Capsule Collider 를 지운다.
5. 빛 번짐을 보려면 Volume 에 Bloom 을 추가하고 카메라의 Post Processing 을 켠다. 레이저처럼 길게 쓰려면 Transform 의 Scale Y 를 키운다.

## 확인
원통 위아래 끝이 부드럽게 사라지고, 무늬가 위아래로 엇갈려 흐르며 일렁인다. 왜곡 세기를 0 으로 내리면 결이 곧게 미끄러지고, 끝단 흐림 길이를 0.02 로 내리면 끝이 또렷하게 끊긴다.

## 기본 머티리얼 값
| 속성 | 뜻 | 값 |
|---|---|---|
| `_EnergyColor` | 에너지 색 | #29B6FF |
| `_Intensity` | 밝기 (HDR) | 2.5 |
| `_ScrollSpeed` | 흐름 속도 | 0.8 |
| `_Tiling` | 무늬 길이 반복 | 1.5 |
| `_DistortStrength` | 왜곡 세기 | 0.12 |
| `_EdgeFade` | 끝단 흐림 길이 | 0.3 |

## 동작 단계
1. **레이어 하나**: 노이즈 텍스처 한 장을 UV 에 시간을 더해 위로 흘린다. 같은 무늬가 통째로 미끄러질 뿐 모양은 변하지 않아 컨베이어 벨트처럼 보인다. 텍스처의 결이 세로로 길어 원통 길이 방향으로 뻗는다. 단계 보기는 더하지 않고 값을 그대로 그려 앞면만 보인다. 아직 끝단 마스크가 없어 무늬가 원통 위아래 끝까지 꽉 찬다.
2. **두 레이어 겹침**: 같은 텍스처를 더 잘게, 아래로 흐르게 한 장 더 읽어 곱한다. 두 무늬의 밝은 곳이 겹치는 자리만 남아 무늬가 계속 바뀐다. 다만 결이 아직 곧아 두 장이 기계적으로 엇갈리는 것이 보인다.
3. **왜곡**: 같은 텍스처를 크게, 느리게 흘려 읽은 값으로 두 레이어의 UV 를 흔든다. 곧던 결이 굽고 일렁여 기운처럼 보인다. 왜곡 세기를 0 으로 내리면 2단계와 같아진다.
4. **끝단 마스크**: 원통 길이 방향 위치로 만든 마스크다. 가운데는 희고 위아래 끝으로 갈수록 어두워져 맨 끝에서는 검다. 끝단 흐림 길이를 줄이면 어두운 띠가 좁아진다. 이 값을 알파로 내보내 끝에서는 아무것도 더하지 않게 한다. 기본 화면에서 원통 윗끝과 바닥 쪽이 부드럽게 사라지는 것이 이 마스크 덕분이다.

## 주의할 점
- 이 셰이더에는 `UniversalForward` 패스 하나만 있어 2D Renderer 에서는 그려지지 않는다. 3D 프로젝트용 효과다. 2D 에서 같은 원리를 쓰려면 스프라이트 셰이더로 옮긴다.
- 노이즈 텍스처 칸이 비어 있으면 `linearGrey`(선형 0.5)가 들어가 무늬와 왜곡 없이 고르게 빛나는 통이 된다. 셰이더를 고쳐 기본값을 `"gray"` 로 두면 Linear 프로젝트에서 약 0.21 로 읽혀 희미한 통만 보인다. 텍스처의 sRGB 가 켜져 있으면 무늬가 어둡고 가늘어진다.
- Bloom 과 톤매핑이 없으면 1 을 넘는 색은 채널마다 1 에서 잘려 번지지 않는다. 기본 색은 파랑과 초록만 1 에 닿아 흰빛까지 가지 않고 옅은 하늘색에서 멈춘다. 카메라의 Post Processing 과 URP Asset 의 HDR 이 켜져 있어야 HDR 값이 Bloom 까지 간다.
- 투명 물체라 깊이를 쓰지 않는다. 투명 효과끼리 겹치면 물체 단위로 정렬되어 순서가 어긋날 수 있지만 더하기 혼합은 순서와 상관없이 결과가 같아 대개 티가 나지 않는다. 안개도 처리하지 않아 Lighting 창에서 Fog 를 켠 씬에서도 먼 빔이 흐려지지 않고 그대로 밝다. 넓은 공간에 쓰면 래퍼에 안개를 넣는다 (변형 예시 참고).
- 끝단 마스크와 흐름은 오브젝트 공간 y 축(높이 -1~1)을 따른다. 레이저처럼 눕히려면 Transform 의 Rotation 으로 돌린다. Batching Static 으로 정적 배칭되면 정점이 월드 좌표로 합쳐져 마스크 위치가 어긋나므로 이 물체는 Static 에서 뺀다.
- 둘레 방향은 메시 UV 의 u 를 쓴다. 높이가 2 가 아니거나 UV 를 다르게 편 메시(직접 만든 리본, 원뿔)는 마스크가 끝에 맞지 않거나 무늬가 옆으로 흐를 수 있다. 다른 메시에 쓸 때는 끝단 마스크가 양 끝에서 0 이 되는지, 무늬가 길이 방향으로 흐르는지 먼저 본다.

## 흔한 실수
- **원통 끝이 칼로 자른 듯 끊긴다**: 알파를 1 로 두거나 끝단 마스크를 곱하지 않으면 메시 경계가 그대로 보인다. 길이 방향 좌표로 `smoothstep` 마스크를 만들어 알파에 곱한다. 뚜껑(캡)이 있는 원통은 뚜껑까지 마스크가 0 이 되도록 UV 대신 오브젝트 높이로 마스크를 만든다.
- **둘레 한 줄에 세로 이음매가 생긴다**: 원통 UV 는 둘레를 한 바퀴 돌아 u 가 1 에서 0 으로 돌아온다. 둘레 방향 타일 수가 정수가 아니면 그 자리에서 무늬가 끊긴다. 둘레 반복은 2, 3 처럼 정수로 둔다. 텍스처 자체도 반복해도 이음매가 없는 것을 쓴다.
- **흐름 속도를 스크립트로 바꾸면 무늬가 튄다**: 흐른 거리를 `_Time.y * 속도` 로 구하므로 실행 중에 속도를 바꾸면 그동안 흐른 시간 전체에 변화량이 곱해져 무늬가 한 번에 건너뛴다. 오래 켜 둘수록 크게 튄다. 속도를 연출로 바꾸려면 C# 에서 `offset += speed * Time.deltaTime` 으로 오프셋을 쌓아 머티리얼에 넘기고, 셰이더는 `_Time.y * 속도` 대신 그 값을 쓴다. 쌓은 값은 레이어 배율(0.7, 0.35)을 곱해도 정수가 되는 주기로 감싼다 (`Mathf.Repeat(offset, 20f)`). Inspector 에서 슬라이더를 끌 때 튀는 것도 같은 이유다.
- **끝이 끊기거나 줄무늬가 길게 번진다**: 텍스처의 Wrap Mode 가 Clamp 이면 UV 가 0~1 을 넘는 순간 가장자리 픽셀이 길게 늘어난다. 흘리는 텍스처는 Repeat 로 둔다. 노이즈는 색이 아니라 데이터이므로 sRGB 도 끈다. 켜 두면 값이 어둡게 휘어 무늬가 어둡고 가늘어진다.
- **빛나지 않고 뿌옇게 덮인다**: 알파 혼합(`Blend SrcAlpha OneMinusSrcAlpha`)이면 뒤를 가리며 섞여 탁해진다. 발광 효과는 `Blend SrcAlpha One` 으로 더한다. Bloom 으로 번지게 하려면 색이 1 을 넘어야 하므로 밝기 값을 1 보다 크게 둔다.

## 변형 예시
- 레이저를 쏠 때 굵기와 밝기가 잠깐 커졌다가 줄어들게 하고 싶다.
- 무늬가 위로 흐르면서 원통 둘레를 따라 비틀려 돌아가는 회오리로 바꾸고 싶다.
- 아래쪽은 흰색, 위쪽은 색이 짙어지게 길이 방향 그라데이션을 넣고 싶다.
- 바닥에 깔리는 원형 마법진(평면 메시)에 같은 효과를 쓰고 싶다.
- 스크립트에서 시작점과 끝점을 정하면 그 사이로 빔이 늘어나게 하고 싶다.
- Fog 를 켠 넓은 씬에서 멀리 있는 빔이 안개 속으로 흐려지게 하고 싶다. 더하기 혼합이라 안개 색이 아니라 0 으로 사라져야 하므로 래퍼에서 `MixFogColor(color, half3(0, 0, 0), fogFactor)` 를 쓴다 (`#pragma multi_compile_fog` 와 정점의 `ComputeFogFactor(positionCS.z)` 가 함께 필요하다).

## Shader Graph 에서 쓰기
Shader Graph 로 옮기려면 먼저 Position 노드(Space 는 Object)의 y 에 Multiply 0.5, Add 0.5 를 해 높이 -1~1 을 길이 좌표 0~1 로 바꾸고, UV 노드의 x 와 Combine 해 레이어의 기본 좌표로 쓴다. Time 노드에 속도를 곱해 Tiling And Offset 노드의 Offset y 에 넣은 레이어 두 개(부호를 반대로, 둘레 Tiling 은 2 와 3 처럼 정수)를 Multiply 로 곱한다. 왜곡은 노이즈를 한 번 더 읽어 0.5 를 빼고 세기를 곱한 값을 두 레이어의 UV 에 Add 한다. 끝단 마스크는 같은 길이 좌표와 One Minus 한 길이 좌표로 Smoothstep(0~끝단 흐림 길이) 두 개를 만들어 곱하고 Alpha 에 넣는다. Graph Settings 는 Surface Type Transparent, Blending Mode Additive, Render Face Both 로 둔다.
